Практики длинной речи

Что индустрия делает со звуком длиннее минуты: чанкование по VAD, контекст предыдущего чанка, temperature=0 и стабильные параметры. И что из этого применить к батчу dictation.

Приговор для твоего батча

Сейчас длинный файл режется без тишины-границ и без контекста между кусками — поэтому на стыках тексты разъезжаются, термины повторяются, а предложений нет. Минимальный рецепт из найденного: VAD-границы вместо таймера, промпт = хвост прошлого чанка, temperature=0, и initial_prompt со списком имён/терминов. У GigaAM hotwords-механизма нет — только промпт.

01

Нарезка: по тишине, не по таймеру

Оптимум чанка — 5–10 минут; границы ставить по VAD-тишине, а не по фиксированным секундам, чтобы не резать слово. Оверлэп 0.1–2 с — только для защиты стыков, не для дедупликации.

  • OpenAI: chunking_strategy="auto" + серверный server_vad с prefix_padding_ms / silence_duration_ms / threshold.
  • ChunkAudio — «split at silences, not at fixed seconds».
  • whisper.cpp: --vad-max-speech-duration-s.
  • Whisper всё равно слушает 30-секундные окна внутри чанка — чанк длиннее 30 с не даёт модели больше контекста сам по себе.
02

Контекст между чанками

Промпт = текст предыдущего чанка — работает: вклейка sot_prev, усечение с хвоста до 224 токенов. Критично: при temperature > 0.5 промпт НЕ переносится — держать temperature=0.

  • condition_on_previous_text — по умолчанию включено; отключать при повторах и галлюцинациях хвоста.
  • Ловушка: слишком длинный накопленный промпт заставляет признавать чанки пустыми — промпт усекать с хвоста.
03

Термины и имена: hotwords — нет

У GigaAM готового механизма hotwords НЕТ: это фича transducer-моделей sherpa (Aho-Corasick, только modified_beam_search, hotwords-file / hotwords-score). Практичный путь для Whisper-конвейера — initial_prompt со списком желаемых слов: имена, жаргон, аббревиатуры — на каждый чанк.

04

Дедупликация и склейка

Правильный конвейер (WhisperX и др.): нарезка БЕЗ оверлэпа, склейка по таймстампам, condition_on_previous_text=False. Дедуп на стыках не нужен, если граница попала в тишину. Оверлэп даёт boundary-repeats — следить за повторами слов на стыках.

05

Параметры стабильности

ПараметрЗначениеЗачем
temperature0 (fallback 0.2–1.0)воспроизводимость; выше 0.5 теряется промпт
vad_filtertrueубирает тишину до распознавания
no_speech_threshold0.6отсекает пустые чанки-галлюцинации
compression_ratio_threshold2.4фильтр дегенеративного повтора

06

Свежие сервисы 2025–2026

  • OpenAI gpt-transcribe / gpt-4o-transcribe — серверный VAD-чанкинг, keywords, потоковый SSE.
  • Gemini 3.5 Transcribe — нативная long-form, диризация, word timestamps, custom vocabulary.
  • Groq whisper-large-v3-turbo — чанкируется только на клиенте (у нас уже так).
  • Cloudflare whisper-large-v3-turbo — $0.000513/аудио-минута (уже подключён).

Что меняем в dictation

1) VAD-границы (тишина ≥ ~300 мс) вместо нарезки по секундам; 2) промпт-чейнинг — хвост прошлого сегмента в следующий запрос; 3) temperature=0 + фильтры из таблицы 05; 4) initial_prompt с терминами в батч-конфиге. У GigaAM hotwords не будет — только через промпт, либо гнать грехом: groq/whisper-large-v3 и так расставляет пунктуацию.
